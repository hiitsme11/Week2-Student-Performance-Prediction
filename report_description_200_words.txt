This project, Student Performance Prediction, demonstrates supervised machine learning for estimating academic outcomes from learning-related features. A reproducible synthetic dataset of 600 sample student records is used so that the project can be executed without exposing real student information. Features include study hours per day, attendance percentage, previous examination score, completed assignments, sleep duration, internet access, parental support, and final score.

The project covers two machine learning tasks. Regression predicts a final score on a scale of 0 to 100. Linear Regression and Random Forest Regressor are compared using Mean Absolute Error, Root Mean Squared Error, and R-squared. Classification predicts pass or fail by converting final scores into labels using a demonstration threshold of 60. Logistic Regression and Random Forest Classifier are compared using accuracy, precision, recall, and F1-score.

The preprocessing workflow handles missing numeric and categorical values, standardizes numeric features, and encodes categorical features using one-hot encoding. The project also includes exploratory analysis, visualizations, model comparison charts, a classification report, and a confusion matrix. The code is organized so the complete workflow can be reproduced using Python and common machine learning libraries.

This project is intended for educational and internship learning purposes. The synthetic data and resulting model scores are not a validated method for judging real students or making academic decisions. The main objective is to understand regression, classification, preprocessing pipelines, model training, and evaluation in a practical end-to-end workflow.
